![License](https://img.shields.io/github/license/hoangtongvu/com.darksun.enum-length-generator)

> [!CAUTION]
> The code generated by the current Generator is not compatible with Burst and cannot be accessed from Burst-compiled code.

> [!NOTE]
> This project was originally created to simplify storing and accessing immutable data in the Burst context. While Unity provides BlobAssets for this purpose, I found them cumbersome to work with and encountered several usability issues. Unfortunately, due to Burst's limited support for static readonly data - even for unmanaged structs, the Generator is currently unable to generate data that can be used in the Burst Context.

## Overview

**SOConstantsGenerator** is a constants generator for ScriptableObjects.

## Installation

To install, paste the following URL into Unity's **Package Manager**:

1. Open **Package Manager**.
2. Click the **+** button.
3. Select **"Add package from git URL..."**.
4. Enter:

```bash
https://github.com/hoangtongvu/SOConstantsGenerator.git?path=/Assets/SOConstantsGenerator
```
